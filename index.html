🗄️ สถานะระบบฐานข้อมูล (Database Engine)

เชื่อมต่อแล้ว (Active)

ระบบจัดเก็บข้อมูลในรูปแบบฐานข้อมูลเชิงสัมพันธ์ (Relational Database: SQLite 3 + IndexedDB) พร้อมข้อมูลผู้ใช้งานจาก user.xlsx

Database Engine: SQLite 3 (Relational Database)
ตำแหน่งจัดเก็บฐานข้อมูล: database/psuwit_it.sqlite
ตาราง students (ผู้เข้าสอบ): 0 รายการ
ตาราง assessments (ผลสอบ): 0 รายการ
การสำรองและจัดการฐานข้อมูล (Backup & Restore)

📐 โครงสร้างตารางฐานข้อมูล (Relational Schema)

ไฟล์โครงสร้างมาตรฐาน: database/schema.sql (รองรับ SQLite, MySQL, PostgreSQL)

1. ตาราง students (นักเรียน 1,465 คน จาก user.xlsx)
id (PK), student_id, class_no, title, first_name, last_name, name, username (UNIQUE), password, grade, room, status, pretest_completed, posttest_completed
2. ตาราง assessments & admins
assessments (ผลสอบรายด้าน D1-D6 คะแนนเต็ม 75 คะแนน) และ admins (ผู้ดูแลระบบพร้อมรหัสผ่าน)

☁️ เชื่อมต่อ Cloud Sync เสริม (External Webhook / Google Sheets)
