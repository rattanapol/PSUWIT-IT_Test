# รหัสนักเรียน ชื่อ-นามสกุล อีเมล (@psuwit.ac.th) ระดับชั้น Pre / Post Test สถานะ จัดการ

🗄️ สถานะระบบฐานข้อมูล (Database Engine)

เชื่อมต่อแล้ว (Active)

ระบบจัดเก็บข้อมูลในรูปแบบฐานข้อมูลเชิงสัมพันธ์ (Relational Database: SQLite 3 + IndexedDB) พร้อมโครงสร้างตารางมาตรฐาน SQL

Database Engine: SQLite 3 (Relational Database)
ตำแหน่งจัดเก็บฐานข้อมูล: database/psuwit_it.sqlite
ตาราง students (ผู้เข้าสอบ): 0 รายการ
ตาราง assessments (ผลสอบ): 0 รายการ
การสำรองและจัดการฐานข้อมูล (Backup & Restore)

📐 โครงสร้างตารางฐานข้อมูล (Relational Schema)

ไฟล์โครงสร้างมาตรฐาน: database/schema.sql (รองรับ SQLite, MySQL, PostgreSQL)

1. ตาราง students (ข้อมูลนักเรียน)
id (PK), student_id, name, email (UNIQUE), grade, status, pretest_completed, posttest_completed, created_at, updated_at
2. ตาราง assessments (ผลการทดสอบสมรรถนะ 6 ด้าน)
id (PK), test_id (UNIQUE), student_id, student_name, email (FK), grade, test_type, score_total, max_score, score_percent, d1_score..d6_score, time_spent_seconds, violations_count, passed, submitted_at

☁️ เชื่อมต่อ Cloud Sync เสริม (External Database / Google Sheets API)

นอกเหนือจากฐานข้อมูลหลักในระบบแล้ว คุณยังสามารถตั้งค่าซิงก์ข้อมูลอัตโนมัติไปยัง Google Sheets หรือ Cloud Webhook ได้อีกด้วย
